## About

I'm Abdulrahman, a self-taught full-stack developer based in Egypt. I build across web interfaces, backend systems, developer tooling, and open-source software.

I care about how software works beneath the surface—not just how it looks. My approach is to understand the system before changing it, investigate edge cases, and verify results with tests and evidence rather than assumptions.

- **Web development:** React, Next.js, TypeScript, JavaScript, Tailwind CSS, and accessible UI design.
- **Backend and data:** Node.js, Express, PHP, Laravel, PostgreSQL, MongoDB, Prisma, and API integrations.
- **Game-server tooling:** Pawn, AMX Mod X, and Counter-Strike 1.6 server plugins.
- **Engineering workflow:** Git, Docker, testing, code review, and AI-assisted development workflows.
